# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, and keep discussion focused on the work. Harassment of any kind is not tolerated.

Report unacceptable behavior by opening a private security advisory on this repository or contacting the maintainer via their GitHub profile. Reports will be handled confidentially.
